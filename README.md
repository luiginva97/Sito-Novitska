# Sito infermieristico e TurniCare

Questa repository privata contiene due applicazioni separate:

- Sito pubblico: file nella root della repository, pubblicato su Cloudflare Pages `sito-infermiera`.
- TurniCare: file nella cartella `/turnicare`, pubblicati su Cloudflare Pages `turnicare`.

Entrambi i progetti sono collegati alla branch `main` e hanno i deployment automatici abilitati.
